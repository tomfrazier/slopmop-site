The open-source version

Slop Mop started as an MIT-licensed project, and that code is still public. The extension, the judging server and the sign library are all there to read, fork and run yourself.

What's in the repo

The extensionThe Chrome extension: reading posts ahead, Hide and Highlight modes, the popup, votes.
The judging serverThe worker behind the /judge endpoint: asks the questions, weighs the answers, returns a score.
The signs and weightsThe questions behind each sign of slop, and how much each one counts.

What you can do with it

Anything the MIT licence allows. Point the extension at your own /judge endpoint, change the weights, or swap the sign library for your own. No permission needed, and nothing about your copy reports back here.

You will need your own access to a model to do the judging. The licence text is in the repo.

How it relates to slopmop.lol

The extension you install from this site is free for one feed, and it talks to a separate, privately run judging server at api.slopmop.lol. That server is not open source and may work differently from the code on GitHub. Using it is covered by the terms of service and the privacy policy.

The open-source code is its own thing: the MIT licence applies to that code, and to nothing else.

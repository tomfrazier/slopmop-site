Slop Mop vs Cringe Guard

Two filters for low-value posts: Cringe Guard runs an LLM on your API key on LinkedIn, Slop Mop scores nine tells across feeds with no key.

What Cringe Guard and Slop Mop each do

Cringe Guard and Slop Mop set out to do much the same job on LinkedIn. Both are browser extensions, and both judge posts on whether they're worth reading rather than on whether AI wrote them.

Cringe Guard is an open-source Chrome extension by Pankaj Tanwar for the LinkedIn feed. As new posts appear, it sends their text to a large language model of your choice through that provider's API, using your own key. The model checks each post against predefined "cringe" indicators (its Chrome Web Store listing names excessive self-promotion, clickbait engagement tactics and irrelevant personal stories) and the extension hides the ones that fail. The project's README on GitHub describes two modes: Blur, which covers a post until you click to view it, and Vanish, which removes it from the page. There's a settings page for choosing the model and customising rules, a mute-words list, an on/off toggle, and a dashboard that counts posts filtered and estimates the time saved.

Slop Mop sends the text of each new post to its own scoring service, where an AI model designed for calibrated decisions answers twelve fixed questions: nine tells of slop (scroll-stopper hooks, engagement bait, hype words, empty praise, no-catch promises, "not X, but Y", flowery prose, stiff phrasing and too-tidy stories) and three counter-signals (sounds like a person, useful to readers, reader response). The post gets a score out of 100 and a verdict. Hide mode folds likely slop into a strip you can reopen; Highlight mode marks it and hides nothing. It does this on LinkedIn, X, Reddit, Facebook, Substack and Medium, on the articles and websites you read, and in Gmail and Outlook, where it checks what the sender wrote. Slop Mop vs Cringe Guard: where they differ

Setup and cost. Cringe Guard is free and open source, but it needs an API key from an AI provider, and whatever that provider charges for the calls is yours to pay. Slop Mop works as soon as it's installed. It's free for one feed with 250 checks a day; Slop Mop XL is US$5.99 a month or US$59.99 a year for every feed, the sites you read, Gmail and Outlook.

Control over the rules. This is where Cringe Guard is stronger, and it's a real difference. You choose the model, edit the filtering rules and add mute words, and because the code is public you can read it, change it or contribute to it. Slop Mop's twelve questions are fixed and the weights on its hosted server aren't published, so you tune it with three sensitivity levels and your votes rather than by rewriting the rules. If you have a precise idea of what you don't want to see, Cringe Guard lets you spell it out.

Reach. Cringe Guard is built for one feed in one browser: LinkedIn, in Chrome. Slop Mop covers the six networks above, the web and your inbox, in Chrome, Edge, Firefox, Safari and other Chromium browsers. If LinkedIn is the only place you mind, that gap doesn't matter to you.

Explanations. Slop Mop shows its working for every post: the score, the strongest signs, and the Slopprint, a chart of all nine tells. Cringe Guard's listing describes a filtered-posts dashboard and the option to view a blurred post, but not a per-post breakdown of why it was flagged.

Uncertainty. Cringe Guard's result depends on the model and prompt you run it with, which is part of its appeal. Slop Mop asks the same twelve questions of every post, and its model reports how sure it is of each answer. When it isn't sure enough overall, the verdict is Not sure and the post is left alone.

Privacy. Both send post text off your machine. Cringe Guard's README says post content goes to an AI model through an API, so it's handled under the terms of whichever provider your key belongs to; its listing says the key itself stays in your browser. Slop Mop never sends your name or the author's, and keeps a one-way hash of the text plus the scores. When you vote against a score, that post's text is kept so the miss can be reviewed.

Upkeep. As of October 2026, Cringe Guard's Chrome Web Store listing shows version 0.0.6, last updated in July 2025. Slop Mop is under active development.

When to use Cringe Guard

  • You already have an API key and don't mind paying for the calls.
  • You want to define "cringe" yourself, down to specific mute words.
  • You want to read or modify the code.
  • LinkedIn in Chrome is the only feed you want filtered.

When to use Slop Mop

  • You want a filter that works on install with no key or prompt-writing.
  • You want each verdict explained, tell by tell, and a Highlight mode that hides nothing.
  • You want to overrule individual calls with a vote.
  • The same habits bother you on X, Reddit, Facebook, Substack or Medium, or in your inbox, and you'd like one tool for all of them.

Using both

Two filters acting on the same feed will fight over the same posts, so run one at a time on LinkedIn. A sensible split is to use mute words for topics you never want to see and a quality filter for everything else; our page on keyword and mute-word filters explains where each approach falls short. If you mainly want to filter AI-looking posts and keep everything on your device, Slop Mop vs DeSlop is the closer comparison. To try the no-setup option, add Slop Mop to your browser and pick the feed you want mopped.
